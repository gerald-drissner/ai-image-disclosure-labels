# Security Policy

## Supported version

Security fixes are applied to the latest released version.

## Reporting a vulnerability

Do not publish a suspected vulnerability in a public GitHub issue.

Send a private report to the maintainer through:

- https://drissner.media/contact/
- https://drissner.media/en/contact-us/

Include:

- affected plugin version;
- WordPress and PHP versions;
- reproduction steps;
- expected impact;
- any proof-of-concept material needed to verify the report.

Please allow reasonable time for investigation and a coordinated fix before public disclosure.
